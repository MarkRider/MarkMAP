# MarkMAP

แอปนำทาง 3D ส่วนตัวสำหรับประเทศไทย (web prototype)

- เปิดใช้งาน: หน้า GitHub Pages ของ repo นี้ (`index.html` = เวอร์ชันล่าสุด)
- เวอร์ชันเก่าอยู่ในโฟลเดอร์ `versions/` (ตอนนั้นยังใช้ชื่อ WITHI)
- API key ต่างๆ (TomTom, Mapillary, Spotify) ใส่ในหน้าตั้งค่าของแอป และเก็บไว้ในเบราว์เซอร์ของเครื่องนั้นเท่านั้น ไม่มีอยู่ในโค้ด
